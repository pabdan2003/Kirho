# Kirho examples

Open these `.csin` projects with **File → Open**. They are intentionally
small, self-contained checks of the editor and simulator.

| File | Demonstrates |
| --- | --- |
| `led-dc.csin` | DC source, resistor, LED, and ground |
| `led-dimmer.csin` | Potentiometer-controlled LED intensity |
| `bjt-fixed-bias.csin` | NPN DC bias and operating point |
| `active-filters.csin` | Active-filter circuit |
| `transformer.csin` | Ideal transformer |
| `power-factor.csin` | AC impedance and power triangle |
| `logic-gates.csin` | Basic digital gates and LEDs |
| `binary-counter.csin` | Digital binary counter |
| `mux-clock.csin` | MUX driven by a clock |
| `555-astable.csin` | NE555 astable oscillator |
| `multimeter-dc.csin` | DC multimeter readings |
| `sheets-net-labels.csin` | Multiple sheets and Net Labels |
| `subcircuit.csin` | Reusable subcircuit instance |
